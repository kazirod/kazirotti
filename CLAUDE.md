# Kazirotti — сайт автоинструктора Ильи Казирода

Мобильный одностраничный сайт, который открывается как Telegram Mini App и как обычный сайт на GitHub Pages.

## Источник правды — макет в Figma
- Файл: https://www.figma.com/design/HkMOdgmNLmd6JuB2ARRNnW (фрейм «taplink v2 — mobile», node 4016:892)
- Компоненты: фрейм «taplink v2 / components» (node 4016:877)
- Тексты, цены и порядок блоков берутся из макета. Если макет и код расходятся — прав макет, спроси у Ивана, прежде чем менять смысл.

## Устройство
- `index.html` — вся разметка, иконки инлайн-спрайтом `<symbol>` в начале body (цвет через currentColor).
- `styles.css` — токены в `:root` повторяют коллекцию переменных Figma «taplink v2». Новые цвета добавлять токеном, а не хексом в правиле.
- `app.js` — `CONFIG` (ник Telegram, номер WhatsApp, ссылки на канал и отзывы) и тексты предзаполненных сообщений `MESSAGES`. Кнопки с пустой ссылкой в CONFIG скрываются автоматически.
- `assets/img/*.webp` — картинки, выгруженные из Figma и сжатые в WebP.
- Сборки нет: статические файлы, деплой — GitHub Pages из ветки `main`.

## Правила
- Mobile first, макет на 393 px; на широких экранах колонка max-width 480 px по центру.
- Шрифт SF Pro Rounded (`ui-rounded` на iOS), запасной — Nunito. Шкала: H1 40/48, H2 32/40, H3 24/32, H4 20/28, Body L 18/26, Body 16/24, Body S 14/20, Caption 12/16, кнопка 18/24.
- Контраст текста — не ниже WCAG AA 4.5:1. Кнопки — не ниже 44 px по высоте.
- Все кнопки записи ведут в Telegram @Kazirotti с предзаполненным сообщением; внутри Telegram ссылки открываются через `tg.openTelegramLink` / `tg.openLink`.
- Анимации: нажатие кнопок (scale 0.97, 160 ms), разовая машинка на маршруте А→Б, появление слов главного заголовка при загрузке, заливка слов в заголовках секций при прокрутке (идёт и обратно, как в «манифесте»), плавное проявление блоков под заголовками (один раз, 16 px / 400 ms). Всё в конце `app.js`; цвета заливки — токены `--fill-from` / `--fill-to`. Новых анимаций без запроса не добавлять. При `prefers-reduced-motion` ничего не включается: слова и блоки сразу видны.

## Проверка перед пушем
Отрендерить страницу на 393 px (Playwright уже есть в окружении) и сверить с макетом: обрезанный текст, горизонтальный скролл, пустые картинки.
